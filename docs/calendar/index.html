登録方法
  • Googleカレンダー（パソコン）　上の「カレンダーに追加」を押し、表示された画面で「追加」を選択します。
  • Googleカレンダー（スマートフォン）　アプリからは追加できません。パソコンのブラウザで一度追加すれば、スマートフォンのアプリにも自動で表示されます。手元にパソコンがない場合は、スマートフォンのブラウザで「PC版サイト」に切り替えると操作できます。
  • iPhone / iPad（標準カレンダー）　設定 → アプリ → カレンダー → アカウント → アカウントを追加 → その他 → 照会するカレンダーを追加 → 上のURLを貼り付け。
  • Outlook　カレンダー画面で「カレンダーを追加」→「インターネットから登録」→ 上のURLを貼り付け。
注意事項
  • 反映まで時間がかかります。更新を取りに行く間隔はカレンダー提供元が決めており、こちらからは変更できません。数時間から1日ほど遅れて反映されると考えてください。急ぎの場合はこのページをご覧ください。こちらは常に最新です。
  • ほぼ毎日、予定が入ります。1年365日のうち314日に「その日の出来事」が登録されています。通知が煩わしい場合は、追加したカレンダーの通知設定をオフにしてください。
  • 過去の出来事は毎年繰り返し表示されます。今後の予定（ライブなど）はその日一度だけの表示です。
  • 不要になったら登録を解除できます。カレンダー一覧の「栗林みな実カレンダー」から解除してください。ご自身の予定には影響しません。
  • 掲載内容に誤りを見つけた場合は、下の連絡先までお知らせいただけると助かります。
